# ฟอนต์ในโปรแกรม

โปรแกรมใช้ IBM Plex Sans Thai น้ำหนัก 400, 500, 600 และ 700 จาก Google Fonts โดยเก็บไฟล์ไว้ใน static/fonts/ibm-plex-sans-thai เพื่อใช้งานในเครื่องโดยไม่โหลดจากบริการภายนอก

- แหล่งต้นฉบับ: https://github.com/google/fonts/tree/main/ofl/ibmplexsansthai
- สิทธิ์การใช้: SIL Open Font License 1.1
- เก็บข้อความลิขสิทธิ์และเงื่อนไขฉบับเต็มไว้ใน src/main/resources/static/fonts/ibm-plex-sans-thai/OFL.txt
- ไฟล์ฟอนต์คงตามต้นฉบับ ไม่ได้แก้รูปแบบตัวอักษร
