# วิธีทดลองระบบโรงแรมครบวงจร

## เปิดโปรแกรม

เปิด PowerShell ใน `Project_new_ver/hotel-app` แล้วรัน:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Hotel.ps1
```

เปิด http://127.0.0.1:8080 แล้วเลือก `reception1`, `reception2` หรือ `reception3` โดยไม่ต้องกรอกรหัสผ่าน ทั้งสามคนทำงานได้เหมือนกัน ระบบระบุผู้รับจอง ผู้รับเช็คอิน และผู้รับเงินตามพนักงานที่เลือก หากเปลี่ยนกะให้กด “เปลี่ยนพนักงาน” มุมขวาบนแล้วเลือกคนใหม่ ประวัติรายการเก่ายังอ้างรหัสพนักงานเดิม

ฐานใช้งานเริ่มจากห้อง 41 ห้องและบัญชีพนักงาน ไม่มีแขกหรือการรับเงินจริงที่แต่งขึ้นให้ ส่วนภาพทดสอบใช้ข้อมูลสมมติในฐาน `hotel_frontdesk_test` แยกต่างหาก

## ทดลองตั้งแต่จองจนพร้อมรับแขกคนถัดไป

1. **ข้อมูลผู้พักและผู้รับเอกสาร:** เพิ่มผู้พักพร้อมชื่อ นามสกุล และเลขเอกสารประจำตัว ส่วนผู้รับเอกสารแยกเป็นบุคคลหรือหน่วยงาน สร้างจากชื่อก่อนแล้วเติมรายละเอียดระหว่างพักได้ หากเป็นหน่วยงานต้องมีที่อยู่และเลขผู้เสียภาษีก่อนออกเอกสาร
2. **ตรวจสอบห้องว่าง:** เลือกประเภทห้อง วันเริ่มพัก วันออก และจำนวนห้อง ทุกครั้งที่ค้นหาจะอ่านฐานข้อมูลใหม่ เลือกห้องที่ต้องการแล้วสร้างการจอง หาก Walk-in สามารถไปหน้าเช็คอินและเลือกห้องที่พร้อมได้
3. **จัดการการจอง:** กรอกชื่อผู้จองและเบอร์โทรแล้วบันทึก ค้นภายหลังด้วยรหัส ชื่อ หรือโทรศัพท์ได้ การเพิ่มหรือลดบางห้องใช้ “แก้ไข” ถ้าไม่เข้าพักทั้งหมดใช้ “ยกเลิกทั้งหมด” การจองที่ยกเลิกทั้งหมดจะไม่แสดงในรายการปกติ หากต้องการค้นประวัติ ให้เลือก “แสดงรายการที่ยกเลิกแล้ว” แล้วกดค้นหา โดยค้นด้วยรหัส ชื่อ หรือโทรศัพท์ได้ ข้อมูลและประวัติเดิมยังอยู่ครบ ห้องที่เช็คอินแล้วไม่เปิดให้เปลี่ยน
4. **เช็คอิน:** เปิดการจองแล้วกด “เช็คอินจากการจอง” หรือเปิดหน้าเช็คอินสำหรับ Walk-in เลือกผู้พัก กุญแจ 1–2 ดอกต่อห้อง และผู้รับเอกสารถ้าทราบ ห้องต้องว่าง สะอาด และใช้งานได้ ทั้งห้องและวันต้องตรงกับรายการจองที่นำมาใช้ ถ้าหลายห้องมีวันออกต่างกันให้แยกเช็คอินตามช่วงพัก
5. **ตรวจการเข้าพัก:** เปิดรายละเอียดเพื่อดูค่าห้องแต่ละคืน ยอดค้าง กุญแจ และผู้รับเอกสาร หากตอนเข้ายังไม่ทราบผู้รับ สามารถเลือกหรือเปลี่ยนค่าเริ่มต้นระหว่างพักได้
6. **รับชำระเงิน:** ค้นหาการพัก เลือกคืนที่รับเงินจริง แล้วระบุเงินสด โอน หรือบัตรให้แต่ละคืน ระบบรวมยอดจากราคาที่บันทึกไว้ แบ่งจ่ายต่างครั้งได้ เช่น คืนแรกเงินสด 800 คืนถัดไปโอน 800 แต่ไม่แบ่งคืนเดียวเป็นเงินสด 300 และโอน 500 ตรวจเวลารับเงินจริงและหลักฐานก่อนยืนยัน
7. **Folio / ใบเสร็จ:** หลังชำระค่าห้องครบ เลือกการพักหนึ่งห้องหรือหลายห้องและโหลดเอกสาร ถ้าทุกห้องมีผู้รับเริ่มต้นคนเดียวกันจะใช้รายนั้น หากต่างกันหรือมีห้องที่ยังไม่ทราบต้องเลือกผู้รับให้ชัดเจน Folio แยกค่าห้องรายคืนและพิมพ์พร้อมช่องลายเซ็นได้
8. **บันทึกใบเสร็จที่เขียนมือ:** เลือกโหมดอ้างอิงใบเสร็จ ตรวจผู้รับ แล้วกรอกเล่มที่ เลขที่ และวันที่ หนึ่งใบรวมการรับเงินหลายครั้งได้ หากบันทึกผิดให้เปิดใบเดิมจากรายการด้านล่างเพื่อแก้ไข ไม่สร้างใบสุดท้ายซ้ำให้การพักเดิม การเปลี่ยนผู้รับเฉพาะใบไม่เปลี่ยนค่าเริ่มต้นของห้อง
9. **เช็คเอาต์:** ตรวจยอดค้างจากข้อมูลล่าสุด ยืนยันว่าแขกออกจริง คืนกุญแจ ตรวจเอกสาร และจัดการเรื่องที่แจ้งไว้แล้ว ไม่ต้องรอแม่บ้านตรวจห้องหลังแขกออก เมื่อบันทึกสำเร็จห้องจะว่างและรอทำความสะอาด ถ้ามีสถานะงดใช้ห้องอยู่จะคงไว้
10. **สถานะห้อง:** เมื่อได้รับแจ้งจากแม่บ้านหรือช่าง ให้พนักงานต้อนรับเลือกห้องแล้วบันทึกความสะอาด การใช้งาน และเหตุผล ซ่อมเสร็จและกลับมาใช้งานได้ไม่ได้ทำให้ห้องสะอาดเอง ห้องพร้อมเข้าพักขณะนี้ต้องว่าง สะอาด และใช้งานได้ครบทั้งสามอย่าง

โดยปกติรับเงินและเตรียมเอกสารในคืนก่อนเช็คเอาต์ โปรแกรมไม่แทนการรับเงินจริง ตรวจหลักฐานธนาคาร เขียนใบเสร็จ หรือแจ้งงานแม่บ้าน/ช่างผ่านช่องทางเดิม

## รายงาน

- **In-house:** ดูการเข้าพัก ณ เวลาที่เลือก โดยไม่ใช้เวลาอ้างอิงในอนาคต
- **Arrival:** ใช้เวลาเข้าจริงในวันที่เลือก แยกจองล่วงหน้ากับ Walk-in
- **Expected Departure:** ดูการพักที่ยังไม่เช็คเอาต์และคาดว่าจะออกตามวันที่เลือก ค่าเริ่มต้นเป็นวันพรุ่งนี้สำหรับเตรียมงานคืนก่อนออก
- **เงินสดรับจริง:** ระบุช่วงเวลาตั้งแต่รวมเวลาเริ่ม ถึงก่อนเวลาสิ้นสุด รวมเฉพาะเงินสด ไม่รวมโอน บัตร ยอดยกมา หรือยอดส่งกะ หนึ่งแถวต่อรายการรับเงินแม้ผูกหลายห้องหรือหลายใบเสร็จ

หลังเปลี่ยนเงื่อนไข ตัวอย่างเดิมจะซ่อนและพิมพ์ไม่ได้จนกดสร้างใหม่ หน้าต่างพิมพ์เป็นการส่งงานให้เบราว์เซอร์ ไม่ยืนยันว่าเครื่องพิมพ์พิมพ์สำเร็จแล้ว

## ปิดและสำรองข้อมูล

```powershell
# ปิดเฉพาะเว็บแอป
powershell -NoProfile -ExecutionPolicy Bypass -File .\Stop-Hotel.ps1
# ปิดทั้งแอปและฐานข้อมูลก่อนสำรอง
powershell -NoProfile -ExecutionPolicy Bypass -File .\Stop-Hotel.ps1 -IncludeDatabase
```

หลังปิดครบแล้ว สำรอง `.runtime/mysql-data` คู่กับ `.runtime/local-settings.json` เก็บในที่ปลอดภัย ห้ามลบ `.runtime` หากต้องการข้อมูลเดิม และอย่าเผยแพร่ไฟล์บัญชีพร้อม source code

หากระบบแจ้งโหลดหรือบันทึกไม่สำเร็จ ให้ตรวจฐานข้อมูลแล้วเปิดรายการใหม่ ระบบไม่แสดงความล้มเหลวเป็นรายงานยอดศูนย์ และธุรกรรมที่บันทึกไม่ครบจะย้อนกลับ

## ดูและกรองสถานะห้อง

หน้าสถานะห้องแบ่งกลุ่มเลขห้อง 14xx, 24xx, 25xx และ 26xx เลือกสภาพห้องจากการ์ดสรุป แล้วกรองต่อด้วยประเภทห้องหรือเลขห้องได้ กด “ล้างตัวกรอง” เพื่อกลับมาดูทั้งหมด ตัวกรองเปลี่ยนเฉพาะรายการที่แสดง ไม่ได้เปลี่ยนสถานะห้อง

จำนวนแต่ละสภาพนับจากห้องทั้งหมดที่โหลดมา ห้องหนึ่งอาจมีหลายสภาพ เช่น มีผู้พักและรอทำความสะอาด จึงไม่ควรนำตัวเลขทุกช่องมาบวกกัน ส่วน “พร้อมเข้าพักตอนนี้” หมายถึงว่าง สะอาด และใช้งานได้ครบทั้งสามอย่าง ไม่ใช่ผลห้องว่างตามวันที่ในหน้าค้นหา

เลือกห้องเพื่อเปิดแบบฟอร์มเดิม พนักงานต้อนรับยังเป็นผู้บันทึกสภาพห้องตามที่แม่บ้านหรือช่างแจ้ง หลังเปลี่ยนตัวกรองสามารถเลือกห้องหรือโหลดหน้าใหม่โดยเก็บเงื่อนไขไว้ได้ การบันทึกสภาพห้องจะกลับมาดูห้องทั้งหมด หากเบราว์เซอร์ปิด JavaScript ยังดูและเลือกห้องได้ครบ แต่ไม่แสดงตัวกรอง
